# OneginDev

Статический сайт-портфолио с двумя языками. Чтобы посмотреть сайт на компьютере, откройте `index.html` в браузере.

## Публикация через GitHub Pages

1. Создайте репозиторий GitHub и загрузите **содержимое** этой папки, сохранив структуру. `index.html`, `site.js`, `style.css`, `.nojekyll` и папка `assets/` должны лежать в корне репозитория.
2. В настройках репозитория откройте **Settings → Pages**.
3. Выберите **Deploy from a branch**, укажите ветку `main` и папку `/(root)`. Если основная ветка называется иначе, выберите её. Нажмите **Save**.
4. После публикации в разделе **Pages** появится адрес сайта.

Сайт работает и по адресу с именем репозитория в пути. Для локального просмотра и публикации достаточно файлов из этой папки. Видео загружаются с YouTube при открытии плеера.

[Инструкция GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)
